About this viewer

A zero-build, browser-based viewer for STEP / IGES / BREP CAD files — parsed in WebAssembly and rendered with WebGL.

Built on

  • three.js — WebGL 3D rendering (source, MIT License)
  • occt-import-js — STEP / IGES / BREP import (OpenCascade compiled to WebAssembly) (MIT License)

occt-import-js wraps Open CASCADE Technology, which is licensed under the LGPL-2.1 with an additional exception.

Both libraries load at runtime from the jsDelivr CDN.
